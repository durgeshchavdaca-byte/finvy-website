SME IPO vs Main Board

Pick the right route.

BSE SME, NSE Emerge, BSE Main Board, NSE Main Board — each has different eligibility, cost, time and investor base.

  • BSE SME — lower eligibility, simpler disclosure, retail-friendly, ₹40 lakh–₹1.5 crore total cost
  • NSE Emerge — slightly stricter SME platform, tech-friendly investor base
  • BSE Main Board — full Main Board, larger issue sizes, retail + QIB + NII allocation
  • NSE Main Board — premier Main Board listing, strongest institutional participation
  • We model both SME and Main Board scenarios upfront and pick based on size, sector and investor appetite
